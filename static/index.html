Prompt Lab

    

    
  

  

    

      
      
    


    

      
Reusable prompt snippets with full version history - every edit creates a new version, nothing is ever lost. Use these when writing a bot's system prompt, or as A/B test variants.

      

    


    

      

        
A/B test two or more system-prompt variants on a published bot. Traffic is split per-conversation (sticky - a chat always sees the same variant). Rate assistant replies with 👍/👎 in chat to build up a real signal, then promote the winner to make it the bot's permanent prompt.
