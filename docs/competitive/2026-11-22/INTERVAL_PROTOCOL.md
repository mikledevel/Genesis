# Проверка интервалов

Протокол зафиксирован до прогона кандидата. Дата — 22 ноября 2026.

Сравниваются исходный empirical-метод и экспериментальный split-метод. По умолчанию приложение сохраняет empirical: улучшение на синтетике само по себе не разрешает объявить калибровку принятой для клиентов.

Split: выбор модели завершается до отдельного калибровочного окна; финальная оценка следует за ним. Для каждого горизонта берётся абсолютный residual, радиус — порядковая статистика с рангом `ceil((n+1)*0.8)`. Если конечную оценку получить нельзя, метод отказывает вместо выдачи выдуманного интервала. После оценки модель переобучается на всей наблюдаемой истории; ошибки наблюдаемого holdout допустимо использовать для будущего диапазона, но не для пересчёта уже объявленной test-метрики.

Это использование conformal-score идеи, а не обещание conformal guarantee для зависимых рядов. Обменность, зависимость окон и сдвиг распределения требуют отдельного рассмотрения. Основания: [Angelopoulos и Bates](https://arxiv.org/abs/2107.07511), [Gibbs и Candès](https://proceedings.neurips.cc/paper_files/paper/2021/hash/0d441de75945e5acbc865406fc9a2559-Abstract.html).

## Данные и границы

- Синтетические типы фиксируются существующим `forecast_baseline.py`: seasonal, trend, noise, intermittent, level_shift.
- Dev: seed 10–13; закрытая synthetic-проверка: seed 100–109. 240 наблюдений истории, следующие 14 полностью скрыты от движка. Предыдущие seed 0/1 остаются диагностикой.
- Каждый тип оценивается отдельно. Level shift — стресс-тест неизвестного будущего события, исключён из обычного coverage go/no-go и публикуется отдельно.
- Основные метрики: покрытие, ширина и interval score (alpha 0.2), затем MAE и WAPE. Никакое снижение interval score не заменяет проверки coverage и наоборот.
- Предварительный gate для обычных seasonal/trend/noise: покрытие ближе к 80%, средний interval score не хуже исходного, средняя ширина не растёт более чем вдвое. Intermittent оценивается отдельно; при непригодности приложение показывает низкую надёжность.
- Результаты с exception входят в failure count. Малый synthetic-набор не является оценкой реальных продаж. Не менять алгоритм после просмотра held-out, чтобы превратить неудачу в прохождение.

После синтетики нужны независимые согласованные ряды клиентов и оценка по горизонтам с учётом зависимости. До этого статус кандидатного метода — экспериментальный.
